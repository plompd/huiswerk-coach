📖 Theorie

§1.1 Fossiele brandstoffen — ontstaan

Miljoenen jaren geleden ontstonden dikke lagen uit afgestorven planten en dieren. Onder hoge druk en temperatuur veranderden die in steenkool, aardolie en aardgas. Omdat ze zo lang geleden gevormd zijn, heten het fossiele brandstoffen.

Aardolie is een mengsel van duizenden koolstofverbindingen en een belangrijke grondstof voor brandstoffen, kunststoffen, medicijnen, verf, lijmen en cosmetica.

Koolstofverbindingen heten ook organische verbindingen — ze komen van oorsprong uit planten en dieren.
§1.2 Gefractioneerde destillatie

Aardolie wordt verhit en verdampt. De damp stijgt in een destillatietoren die naar boven toe kouder wordt. Op elke hoogte condenseert een fractie: stoffen met ongeveer hetzelfde kookpunt.

Hoog kookpunt → laag in de toren (dikke, zware moleculen). Laag kookpunt → hoog in de toren (lichte gassen).

Benzine en gasolie worden daarna ontzwaveld (zwavelverbindingen geven schadelijk zwaveldioxide). Additieven verbeteren de verbranding.

§1.3 Het kraakproces

Destillatie levert maar 30–40% benzine per vat olie — te weinig. Daarom wordt extra benzine gemaakt door kraken: een ontledingsreactie waarbij lange koolstofverbindingen in kleinere moleculen worden gebroken. Minstens één kleiner molecuul bevat altijd een dubbele binding (een alkeen).

C₂₀H₄₂ → C₉H₂₀ + C₇H₁₄ + ?
C: 20 − 9 − 7 = 4 · H: 42 − 20 − 14 = 8 → ? = C₄H₈
Kloppend maken = tel C en H links, trek de bekende stoffen eraf. Wat overblijft is de onbekende stof.
§2.1 Molecuul- en structuurformule

Een molecuulformule geeft het aantal en soort atomen (bv. CH₄). Een structuurformule laat met streepjes zien hoe de atomen verbonden zijn. Vaste regels (covalentie): C = 4 bindingen, O = 2, H = 1.

methaan (CH4):

    H
    |
H — C — H
    |
    H

Een functionele groep is een atoomgroep of meervoudige binding die de eigenschappen bepaalt (bv. een dubbele binding of een –OH-groep).

§2.2 Alkanen

Alkanen bestaan alleen uit C en H met enkelvoudige bindingen, geen functionele groep. Algemene formule:

alkaan: CnH2n+2

§2.3 Alkenen

Alkenen bestaan ook alleen uit C en H, maar met één dubbele binding (de functionele groep → reactiever). Algemene formule:

alkeen: CnH2n
etheen (C2H4):

H       H
 \     /
  C = C
 /     \
H       H

Alkenen ontstaan o.a. bij het kraken. Uit etheen (C₂H₄) wordt de kunststof PE (polyetheen) gemaakt — plastic tassen en verpakkingen. Ander voorbeeld: propeen (C₃H₆).

§2.4 Alkanolen

Vervang in een alkaan een H door een –OH-groep → een alkanol (uitgang -anol).

methanol (CH3OH):       ethanol (C2H5OH):

    H                   H   H
    |                   |   |
H — C — O — H       H — C — C — O — H
    |                   |   |
    H                   H   H

Ethanol (C₂H₅OH) = "alcohol", oplosmiddel en in drank. Methanol (CH₃OH) is giftig en wordt aan spiritus toegevoegd zodat het niet drinkbaar is.

§2.5 Isomeren

Isomeren = dezelfde molecuulformule, andere structuurformule. Van C₄H₁₀ bestaan een rechte en een vertakte vorm:

recht (butaan):             vertakt (2-methylpropaan):

    H   H   H   H               H   H   H
    |   |   |   |               |   |   |
H — C — C — C — C — H       H — C — C — C — H
    |   |   |   |               |   |   |
    H   H   H   H               H   C   H
                                    |
                                    H
Vertakt molecuul → boller → minder contact → zwakkere vanderwaalsbinding → lager kookpunt. Twee isomeren zijn dus echt verschillende stoffen (verschillend kook-/smeltpunt).
§2.6 Systematische naamgeving (stappenplan)

Stap 1 — stamnaam. Tel de C-atomen in de langste keten → stam (meth, eth, prop, but, pent, hex, hept). Soort verbinding → uitgang: alkaan -aan, alkeen -een, alkanol -anol.

Stap 2 — zijketens. methyl- (–CH₃), ethyl- (–C₂H₅). Bij meerdere: alfabetische volgorde, vóór de stamnaam.

Stap 3 — plaatsnummers. Nummer de C-atomen. Begin tellen aan de kant die de functionele groep het laagste nummer geeft: eerst –OH, anders dubbele binding, anders zijketens zo laag mogelijk.

Voorbeeld: 4 C-atomen, geen zijketens, geen functionele groep → butaan. 2 C-atomen + –OH → ethanol.
§2.7 Oplossen in water (–OH-groep)

Stoffen met een –OH-groep lossen beter op in water. De –OH-groep lijkt op water (ook O–H) en maakt goede aantrekking met watermoleculen. Hoe langer het koolstofdeel, hoe slechter het oplost — daarom lost ethanol prima op, maar een lang alkanol veel minder.
